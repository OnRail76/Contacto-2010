# CONTACTO 2010 — V1.1

Edición final de **Tony C. Ware** con GRIT NOVA ENGINE (C++17, SDL2 y libpng). Banda sonora original de **FutureDark**, alias musical de Tony C. Ware.

## DESCARGAS PARA JUGAR

**Linux x86_64:** `Contacto_2010_V1.1-x86_64.AppImage` — archivo AppImage real; en una terminal: `chmod +x Contacto_2010_V1.1-x86_64.AppImage`, y ejecutarlo.

**Windows 64 bits:** `CONTACTO_2010_V1.1_WINDOWS_x64.zip` — descomprimir COMPLETO y abrir `CONTACTO_2010.exe` (con icono oficial, DLL nativas y recursos incluidos). No precisa Python ni Wine.

**Linux clásico:** `CONTACTO_2010_V1.1_LINUX_COMPLETO.zip` — descomprimir y ejecutar `JUGAR_CONTACTO_2010.sh`.

## CONTENIDO

Cinco fases completas y jefes propios, nueva Firebird-01 industrial, Cementerio de Escombros V2, HUD militar, escudo, indicadores, controles WASD y flechas, reconexión de mandos, banda sonora original y narrativa de transmisiones.

Incluye **atlas/memoria/manual PDF de 44 páginas**, fuentes separadas de CONTACTO 2010 y GRIT NOVA ENGINE, iconos oficiales y ficheros SHA256. El antiguo kit AppDir se conserva para quienes quieran reconstruir un AppImage; el archivo terminado ya está disponible arriba.

## VERIFICACIONES

GitHub Actions comprueba Linux, AppImage y EXE Windows desde código C++17; ambos formatos se publican en esta Release solo tras superar sus pruebas automatizadas. Como última validación siempre recomendamos una partida real con monitor y mando.
