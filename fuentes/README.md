# Fuentes de CONTACTO 2010 V1.1

`contacto_native.cpp` implementa el juego y enlaza con el núcleo reutilizable de `motor/grit_nova_engine.hpp`. Son las **fuentes originales del juego**, no del núcleo independiente.

La lógica del juego comprende la campaña de cinco fases, eventos de oleadas, enemigos, jefes, diálogo, HUD militar, disparos, efectos, colisiones, grabado de récord y pruebas automatizadas. Los recursos se cargan desde `assets/` al ejecutar desde la raíz.

Para compilar el conjunto: `./COMPILAR_LINUX.sh`.

No se proporciona un binario Windows probado. El alias musical FutureDark corresponde al creador Tony C. Ware; su música y el arte gráfico se conservan con créditos propios, aparte de la licencia de software MIT.
